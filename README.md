CS-330 Final Project

My project is a 3D kitchen scene built with C++ and OpenGL, featuring an onion, cutting board, cup, and bowl.

How do I approach designing software?

I break projects into smaller pieces and build a basic version first. This project taught me how to combine simple shapes into objects, such as using cylinders and a torus for the cup. I started with shapes and placement, then added textures and lighting. I can use this approach in future projects to test designs before adding details.

How do I approach developing programs?

I work incrementally and check the results as I go. I adjusted texture scaling, rebuilt parts of the cup and bowl, and refined the lighting through repeated testing. Throughout the milestones, I became more comfortable identifying which part of the code needed adjustment and making focused changes.

How can computer science help me in reaching my goals?

This project strengthened my C++ and debugging skills while helping me understand coordinates, transformations, and lighting. That experience will support my remaining coursework and future software development work. Breaking down problems and testing changes are skills I can apply beyond graphics.
